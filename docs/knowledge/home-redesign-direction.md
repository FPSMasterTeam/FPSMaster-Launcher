# Launcher 首页设计方向

首页是竞技玩家的“出战台”：用当前实例、账号和配置快速进入常用服务器，而不是通用门户或欢迎页。

## 信息与交互

- 主区展示当前实例、关键规格、当前账号和明确启动动作。
- 常用服务器提供直接快速加入；通用启动入口保留但不重复抢占层级。
- 真实统计存在时展示，不用虚构空数据填充。
- 技术数值使用等宽字体；强调色只表达可启动、在线、焦点或激活。
- 侧栏使用固定窄轨和悬浮展开，不推动正文重排。

## 视觉规则

采用紧凑圆角、平面不透明表面、细边框和轻量中性阴影。禁止渐变填充、光晕、脉冲点、描边胶囊、无意义小标题、冗余描述及 Sparkles 类 AI 套路图标。按钮不悬浮跳动。空状态应给出下一步行动。所有文字、控件和区块保持充足字距、行距及元素间距。
